Developed and managed the implementation of "ApexsMed LIMS V3.0" (Laboratory Information Management System), a comprehensive healthcare platform designed to automate clinical laboratory workflows.

Key achievements and responsibilities in this project:
- Software Architecture & Backend: Engineered a highly secure and scalable Python-based backend architecture integrated with relational databases (PostgreSQL) to safely handle and store patient diagnostics, test results (e.g., Biochemistry, Hematology, Immunology), and dynamic pricing structures.
- Frontend Development: Designed and built a pixel-perfect, lightning-fast dashboard interface using semantic HTML5, CSS3, and JavaScript, focusing on medical staff efficiency and automated status tracking (e.g., "Tayyor", "Kutmoqda", "Shoshilinch").
- Integration & Automation: Successfully built robust REST APIs for laboratory equipment data ingestion, automated result validation, and real-time medical billing modules.
- Project Delivery: Led the full software development lifecycle (SDLC) from abstract conceptualization and business requirements analysis to a production-ready cloud deployment.
